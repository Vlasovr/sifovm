# План выполнения ЛР5-8

## 1. Анализ требований

- Извлечены задания из PDF для ЛР5-8.
- Вариант взят из курсового проекта, чтобы лабораторные не расходились с будущей микро-ЭВМ.
- Готовый пример товарища использован как ориентир по составу проекта, стилю проверки и структуре отчета.

## 2. Проектирование

- ЛР5: выделены блоки `alu_control`, `OR`, `NOR`, `SRA`, `INCS`, `flags`.
- ЛР6: выделены `stack7x16`, `stack_control`, верхний модуль с выбором источника `reg/ALU`.
- ЛР7: выделены `master_device`, центральный арбитр, MUX шины, синхронный slave.
- ЛР8: выделены контроллер кэша, массивы tag/data/age/valid, интерфейс RAM.

## 3. Реализация

- Создана папка `student_labs_5_8`.
- Для каждой лабораторной созданы:
  - `src/` с VHDL;
  - `tb/` с testbench;
  - `quartus/` с `.qpf/.qsf`;
  - `report/` с DOCX-отчетом.

## 4. Проверка

- Все testbench запущены через GHDL.
- Все проекты собраны в Quartus II 9.1.
- Отчеты переписаны в подробном формате по образцу товарища: титульный лист, содержание, теория, исходные данные, описание сигналов, алгоритм, VHDL-реализация, моделирование и вывод.
- DOCX отрендерены через LibreOffice в PDF/PNG и визуально проверены по контактным листам.

## 5. Что осталось сделать руками перед сдачей

- При необходимости снять реальные скриншоты из Quartus по файлу `Что_снимать_в_Quartus.md`.
- На защите открыть RTL Viewer верхнего модуля `*_rtl_view_top`, потому что там пины подписаны развернутыми именами и сразу видно назначение входов, выходов и диагностических линий.
