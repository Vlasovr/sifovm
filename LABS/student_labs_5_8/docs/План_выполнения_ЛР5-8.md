# План выполнения ЛР5-8

## 1. Анализ требований

- Из заданий выделен индивидуальный вариант 4 для каждой лабораторной работы.
- Параметры согласованы с курсовым проектом: 16-разрядные данные, единая система кодов команд, совместимая структура верхних уровней.
- Пример товарища использован как ориентир по составу отчета, последовательности объяснения, стилю таблиц и подписям рисунков.

## 2. Проектирование

- ЛР5: выделены блоки управления операцией, сравнения `CMP`, поразрядной операции `NOR`, арифметического сдвига `SRA`, мультиплексора результата и формирования флагов.
- ЛР6: выделены стековый массив `7x16`, блок управления командами `PUSH/POP/PUSH_ALU`, мультиплексор источника данных и блок контроля границ.
- ЛР7: выделены ведущие устройства, центральный арбитр, мультиплексор общей шины и синхронный ведомый приемник.
- ЛР8: выделены блок разбора адреса, массив строк кэша, компаратор тега, контроллер попадания/промаха и интерфейс основной памяти.

## 3. Реализация

Для каждой лабораторной создан одинаковый комплект:

- `src/` с описанием функциональных блоков;
- `tb/` с проверочным стендом;
- `quartus/` с проектом Quartus;
- `report/` с итоговым отчетом;
- общие изображения схем и временных диаграмм в `assets/`.

## 4. Проверка

- Модельные стенды проверяют основные штатные режимы и граничные ситуации.
- Проекты собраны в Quartus II 9.1; итоговые журналы сборки сохранены в папках `quartus/`.
- DOCX-отчеты отрендерены в PDF/PNG и визуально проверены по страницам: титульный лист, содержание, таблицы, рисунки, подписи, выводы.

## 5. Что проверить руками перед сдачей

- Открыть нужный DOCX и убедиться, что на титульном листе указан `Власов Р.Е.`.
- Сверить, что в отчете по ЛР5 фигурируют `CMP`, `NOR`, `SRA`; по ЛР6 указан рост к большим индексам; по ЛР8 указано прямое отображение на 8 строк.
- В Quartus открыть схему верхнего уровня и сделать скриншот с видимыми именами входов, выходов и диагностических линий.
- При необходимости снять временную диаграмму по файлу `docs/Что_снимать_в_Quartus.md`.
