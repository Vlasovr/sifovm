# Лабораторные работы 5-8 по СиФО ЭВМ

Комплект выполнен под индивидуальный вариант 4 и связан с курсовым проектом по составу будущей микро-ЭВМ.

- ЛР5: арифметико-логическое устройство с операциями `CMP`, `NOR`, `SRA`.
- ЛР6: стековое запоминающее устройство на 7 слов по 16 бит; стек заполняется к большим индексам, указатель показывает последнюю занятую ячейку.
- ЛР7: централизованный параллельный арбитраж общей шины с фиксированным квантом времени.
- ЛР8: кэш-память прямого отображения на 8 строк со сквозной записью.

## Структура

| Папка | Содержимое |
|---|---|
| `common/` | общий пакет с константами варианта и кодами команд |
| `lab5_alu/` | проект АЛУ, проверочный стенд, отчет |
| `lab6_stack/` | проект стекового ЗУ, проверочный стенд, отчет |
| `lab7_bus_arbiter/` | проект арбитража шин, проверочный стенд, отчет |
| `lab8_cache/` | проект кэш-памяти, проверочный стенд, отчет |
| `assets/` | схемы, временные диаграммы и изображения для отчетов |
| `docs/` | инструкции по ручной проверке и подготовке к защите |
| `sim/` | общий запуск модельных проверок и файлы дампов |

## Проверка

Общая модельная проверка:

```powershell
cd D:\git\sifovm\LABS\student_labs_5_8\sim
powershell -ExecutionPolicy Bypass -File .\run_all_ghdl.ps1
```

Ожидаемый результат: все четыре стенда завершаются строкой `TEST PASSED`, дампы создаются в `sim/vcd/`.

Сборка проектов в Quartus:

```powershell
cd D:\git\sifovm\LABS\student_labs_5_8\lab5_alu\quartus
quartus_sh --flow compile lab5_alu

cd D:\git\sifovm\LABS\student_labs_5_8\lab6_stack\quartus
quartus_sh --flow compile lab6_stack

cd D:\git\sifovm\LABS\student_labs_5_8\lab7_bus_arbiter\quartus
quartus_sh --flow compile lab7_bus_arbiter

cd D:\git\sifovm\LABS\student_labs_5_8\lab8_cache\quartus
quartus_sh --flow compile lab8_cache
```

Проверено: все четыре проекта компилируются в Quartus II 9.1 без ошибок. Предупреждения о незакрепленных выводах допустимы для учебного функционального проекта без привязки к конкретной плате.
